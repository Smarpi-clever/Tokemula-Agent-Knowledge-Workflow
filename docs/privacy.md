# 隐私与数据保存

## 读取范围

设置向导检测 Python、Git、Codex、操作系统和已有安装；检查所选项目、知识库及相关 Hooks 和 Git 绑定。发现 Obsidian Vault 时读取注册信息和用户选择范围的目录名，不打开候选目录的笔记正文。

自 0.2.0 起，向导新建的配置默认设置 `project_snapshot=false`，不在任务开始时遍历并读取整个项目来生成内容快照。维护使用当前任务的工具活动回执；提交事实时，逐项读取所需的文件或固定 commit 内容，校验路径、摘要和短摘录。工具活动回执仅说明观察到了活动，文件事实仍由对应文件或 commit 证据验证。

旧配置缺少该字段时保留原有项目快照行为。升级程序会保留旧配置；应通过设置向导检查实际映射后，再按新的读取范围启用。此兼容行为在配置迁移前持续有效。

为生成知识主题目录，工具在本机读取配置知识库中所有 `topics/*.md` 文件的正文，提取标题并计算文件摘要。目录结果只输出标题、身份和来源等元信息；Agent 再按任务选择相关主题。笔记内容作为参考数据处理，不授予命令或路径权限。

`akf doctor --verify` 核对最近维护任务的原生 Hook 和工具回执。验证内部维护来源时，通过 Codex 原生查询取得对应聊天记录的位置，最多读取该本机记录末尾 4 MiB，匹配同一任务的隐藏 Hook 上下文、来源标记和随机标识。工具不输出或另存聊天正文；缺少原生来源记录时保留待验证状态。

## 本地保存

程序、配置和状态与用户知识库分开：

| 内容 | macOS 默认位置 |
|---|---|
| 工具版本 | `~/.local/share/agent-knowledge-workflow/` |
| 配置、状态、事务与恢复记录 | `~/Library/Application Support/AgentKnowledgeWorkflow/` |
| 启动入口 | `~/.local/bin/akf` |
| 用户知识 | 设置时选择的独立目录 |

状态记录包含映射路径、源身份与摘要、任务和回执标识、结构化执行结果、候选事实、短证据摘录、pending 和写入历史。原始提示正文、完整命令、工具日志、环境值和完整聊天记录不由工具作为日志保存。

自动更新只写 `topics/*.md` 的工具托管块。人工正文、索引和 Obsidian 配置保留；冲突及来源不足的候选保留供审阅。笔记可能包含你同意保存的项目知识，请按项目隐私要求审查内容。

## 网络与模型

本工具不调用额外模型 API，不建立独立 Provider 连接，也不复制模型凭据。知识维护由当前 Agent 会话执行，因此该会话本身的数据处理方式仍由你选择的 Agent 和 Provider 决定。

仅本地保存时，本工具不推送知识库。启用 GitHub 自动推送后，工具通过已配置的 Git 连接推送授权笔记，并使用 GitHub CLI 校验私有仓库身份。Git 认证沿用用户环境。

系统依赖由用户从官方来源安装。可选 Obsidian CLI 仅在显式配置且应用已运行时使用。

## 暂停、卸载与保留

`akf pause` 或 `akf disable` 停止所选项目的后续自动维护。`akf uninstall` 处理整个安装，禁用全部已登记项目映射并移除工具拥有的入口和接入配置，保留笔记、配置、pending、状态、事务和版本恢复副本。

恢复按原绑定重新核对授权及证据；用户后续修改产生冲突时保留当前文件。需要清除保留数据时，先核对是否仍有 pending 或恢复需要，再由用户选择具体目录处理。卸载不会自动删除知识库。

问题反馈应使用合成材料。安全问题见 [SECURITY.md](../SECURITY.md)。
